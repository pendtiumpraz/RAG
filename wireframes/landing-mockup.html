Kenapa Nalar

Penalaran yang membumi, bukan tebakan yang meyakinkan.

I

Bersumber

Setiap jawaban ditarik dari dokumenmu dan diberi catatan kakin yang bisa diklik. Tidak ada klaim tanpa sumber.

II

Terisolasi

Tiap tenant dikurung Row-Level Security di database. Basis pengetahuan mustahil bocor antar tenant — dijamin mesin, bukan janji.

III

Terbuka & milikmu

Model apa pun — lokal 80MB/2GB atau API. White-label penuh: logo, warna, radius, huruf. On-prem bila perlu.

Cara kerja

Dari dokumen ke jawaban dalam empat langkah.

Hubungkan sumber

Google Drive, OneDrive, SharePoint milikmu — atau unggah file.

Pilih model

Satu model embedding & satu LLM aktif, dari semua provider.

Sematkan widget

Satu baris <script> di website mana pun. API key tetap di server.

Jawab & kutip

Pengunjung bertanya; Nalar menjawab dari KB-mu, lengkap dengan catatan kaki.

Embed di mana saja

Satu ID chatbot, satu knowledge base.

Setiap chatbot punya public key sendiri. Tempel di situs mana pun; respons mengalir kata demi kata. ID berbeda berarti pengetahuan berbeda — terisolasi sepenuhnya.

  • ✓ Origin allow-list per chatbot
  • ✓ White-label: warna, radius, huruf, logo
  • ✓ API key server-to-server — tak pernah menyentuh browser
